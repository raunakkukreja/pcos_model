═══════════════════════════════════════════════════════════════════════════════
                               ENVIRONMENT COMMANDS
═══════════════════════════════════════════════════════════════════════════════

1. ACTIVATE CONDA BASE (if needed):
   conda activate base

2. LIST ALL CONDA ENVIRONMENTS:
   conda env list

3. ACTIVATE TRAINING ENVIRONMENT (for model training):
   conda activate pcod_env
   .\pcod_env\Scripts\Activate.ps1

4. ACTIVATE BACKEND ENVIRONMENT (for running FastAPI):
   conda activate ipl_fantasy

═══════════════════════════════════════════════════════════════════════════════
                                 FRONTEND COMMANDS
═══════════════════════════════════════════════════════════════════════════════

1. NAVIGATE TO FRONTEND:
   cd c:\coding\my projects\PCOS\website\frontend

2. INSTALL DEPENDENCIES:
   npm install

3. RUN DEVELOPMENT SERVER (Vite):
   npm run dev
   * This starts the React app at http://localhost:5173/

4. BUILD FOR PRODUCTION:
   npm run build

═══════════════════════════════════════════════════════════════════════════════
                                 BACKEND COMMANDS
═══════════════════════════════════════════════════════════════════════════════

1. NAVIGATE TO BACKEND:
   cd c:\coding\my projects\PCOS\website\backend

2. INSTALL DEPENDENCIES:
   pip install -r requirements.txt

3. RUN BACKEND SERVER - OPTION A (Using Script - EASIEST):
   .\run_backend.ps1
   * This automatically activates ipl_fantasy env and starts the server

4. RUN BACKEND SERVER - OPTION B (Manual):
   python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
   * Flags:
     --reload     : Auto-restart on code changes
     --host 0.0.0.0 : Server accessible from other machines
     --port 8000  : API runs on port 8000

5. ACCESS API DOCUMENTATION:
   http://localhost:8000/docs (Interactive Swagger UI)
   http://localhost:8000/openapi.json (OpenAPI schema)

6. TEST PREDICTION ENDPOINT:
   POST http://localhost:8000/api/v1/predict
   * Use the Swagger UI at /docs to test

═══════════════════════════════════════════════════════════════════════════════
                              MODEL TRAINING COMMANDS
═══════════════════════════════════════════════════════════════════════════════

1. ACTIVATE TRAINING ENVIRONMENT:
   conda activate pcod_env

2. NAVIGATE TO MODELS DIRECTORY:
   cd c:\coding\my projects\PCOS\models

3. TRAIN THE MODEL:
   python train_xgboost.py
   * This generates xgb_model.pkl (used by backend)
